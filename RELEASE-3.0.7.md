# Flow Remote Helper 3.0.7

- В настройках бессрочные ключи показываются как «Бессрочно», без вымышленной даты окончания.
- В Telegram-боте обновлено главное меню: описание, «Получить ключ» и «GitHub».
- Первый тестовый ключ выдаётся один раз на 72 часа. После подтверждённой оплаты 50 Stars этот же ключ становится бессрочным. Повторная покупка для уже бессрочного доступа не предлагается.
- Существующие ключи и их сроки сохраняются. Ключ при обновлении расширения повторно вводить не нужно.

## Скачать

- `FlowRemoteHelper-Setup-3.0.7.exe` — установщик Windows.
- `flow-remote-helper-vps-3.0.7.zip` — расширение для ручной установки.
- `SHA256SUMS.txt` — контрольные суммы.

Запустите установщик и нажмите ↻ у расширения в `chrome://extensions` в нужном профиле. Установка вне Chrome Web Store; EXE пока не подписан сертификатом издателя.

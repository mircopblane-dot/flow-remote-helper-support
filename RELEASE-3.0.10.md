# Flow Remote Helper 3.0.10

Исправлена ошибка чистой установки: если ключ ещё не сохранялся, настройки могли показывать «Фоновый процесс недоступен» вместо формы ввода ключа. Теперь новая установка и профиль без сохранённого ключа корректно показывают активацию.

Существующие ключи, сроки и подключённый помощник сохраняются. Данные, передаваемые сервисам, не изменились.

## Обновить

С подключённым помощником: в настройках нажмите «Проверить обновления» → «Обновить до 3.0.10». Раздел обновлений работает независимо от состояния карточки ключа.

Без помощника или для новой установки: скачайте `FlowRemoteHelper-Setup-3.0.10.exe`, запустите его и нажмите ↻ у расширения в chrome://extensions. ZIP доступен для ручной установки. В нужном профиле должна быть включена одна версия Flow Helper.

`flow-remote-helper-update-3.0.10.json` — подпись для помощника; `SHA256SUMS.txt` — контрольные суммы. EXE пока не подписан сертификатом издателя.

# Какие данные передаёт Flow Remote Helper

Flow Remote Helper проверяет ключ доступа и получает с нашего сервера настройки для текущей версии Flow. Для работы расширения нужен интернет. Ниже описано поведение версии 3.0.4.

## Что отправляется на сервер

- **Ключ доступа** — для проверки лицензии.
- **Версия Flow и публичный адрес её JavaScript-файла** — для получения подходящих настроек. Версия может содержать язык интерфейса.
- **Случайный идентификатор запроса** — чтобы проверить, что ответ относится к этому запросу.

Данные передаются по защищённому соединению HTTPS. Проверка выполняется при открытии Flow и периодически, пока вкладка открыта. При временном сбое расширение повторяет попытки.

Сервер также видит IP-адрес подключения и стандартные заголовки браузера. В статистике сервиса сохраняются время, результат и длительность проверок, версия Flow и число обращений по ключу. IP-адрес и сведения о браузере в эту статистику не записываются.

## Что не отправляется на наш сервер

- Cookies, пароли и токены Google.
- Имя, email и содержимое Google-аккаунта.
- Проекты Flow, промпты, изображения, видео и результаты генераций.
- Содержимое и снимки страниц, история посещений.
- Локальные файлы, буфер обмена и список профилей Chrome.

Сам Flow продолжает обмениваться данными с Google обычным образом.

## Что расширение получает

Результат проверки доступа и настройки совместимости с Flow. Расширение проверяет подпись ответа перед применением. Исполняемый код с нашего сервера не скачивается.

## Что остаётся на компьютере

Ключ хранится локально в выбранном профиле Chrome. Полученные настройки временно сохраняются во вкладке Flow; ключ в хранилище страницы не записывается.

Установщик размещает файлы на компьютере и показывает доступные профили Chrome. Их названия и пути никуда не отправляются. Сам установщик не выполняет сетевых запросов.

# Какие данные передаёт Flow Remote Helper

Это описание относится к версии 3.0.3. Flow Remote Helper работает как расширение Chrome и использует собственный сервер для проверки лицензии и получения актуальных параметров совместимости с текущей версией Flow. Для VPS edition требуется интернет.

## Запросы расширения на наш сервер

Расширение обращается по HTTPS к `95.182.96.230:8443`. Оно передаёт:

| Данные | Для чего |
| --- | --- |
| Ключ лицензии | Проверить статус и срок доступа |
| Идентификатор текущей сборки Flow | Подобрать совместимые параметры; идентификатор может включать язык интерфейса |
| Публичный адрес JavaScript-файла этой сборки на www.gstatic.com | Определить, к какой версии Flow относится запрос; адрес передаётся без query-параметров и fragment |
| Случайное значение запроса | Связать ответ с конкретной проверкой |

Ответ сервера содержит статус подготовки или подписанные параметры совместимости и срок разрешения. Ответ проверяется расширением перед применением. Исполняемый код расширения с нашего сервера не скачивается. Проверки выполняются при запуске Flow и затем периодически, пока вкладка открыта. При временном сбое запросы повторяются автоматически.

Как при любом HTTPS-соединении, наш сервер получает IP-адрес подключения и стандартные сетевые заголовки, которые формирует браузер, например User-Agent. Это не отдельное сканирование компьютера. Прикладная статистика сервиса хранит связь с лицензией, время обращения, результат проверки, код ответа, длительность обработки, число запросов и сведения о сборке. IP-адрес и User-Agent в эту прикладную статистику не записываются. Доступ к сетевым метаданным также может иметь инфраструктура хостинга.

## Что расширение не передаёт на наш сервер

В версии 3.0.3 в запросы не включаются:

- Cookies, пароли, токены авторизации и данные входа Google.
- Имя, email и содержимое Google-аккаунта.
- Проекты Flow, промпты, фотографии, видео и результаты генераций.
- HTML страницы, её снимки и история посещения других сайтов.
- Список Chrome-профилей, локальные файлы или содержимое буфера обмена.

Сам Flow продолжает обращаться к Google обычным образом. Расширение не перенаправляет весь интернет-трафик через наш сервер и не заменяет VPN. Установка расширения не даёт доступ к чужим аккаунтам или подписке Google.

## Что остаётся на компьютере

Ключ хранится в локальном хранилище расширения в выбранном профиле Chrome. Во вкладке Flow временно сохраняются полученные параметры; ключ лицензии в хранилище страницы не записывается.

Windows-установщик распаковывает файлы локально. Он читает названия и каталоги Chrome-профилей, чтобы предложить нужный профиль, но не отправляет их на сервер. Сам установщик не выполняет сетевых запросов, не запрашивает права администратора и не создаёт фоновую службу.

## Telegram-бот и оплата

Если вы получаете ключ через [@testery_ai_bot](https://t.me/testery_ai_bot?start=flow), Telegram передаёт боту ваш Telegram ID и сообщения/нажатия, адресованные боту. Для выдачи и восстановления доступа сервис хранит Telegram ID, связь с лицензией, тип доступа и срок. Полный ключ хранится на сервере в зашифрованном виде и доступен администратору сервиса.

При покупке сохраняются номер заказа, время, состояние оплаты и идентификатор транзакции Telegram. Цена годового доступа — 50 Stars, валюта XTR. Бот не запрашивает данные банковской карты; оплату обрабатывает Telegram. Подтверждённые события оплаты могут оставаться в служебной очереди до завершения выдачи доступа.

## Поддержка и сроки хранения

Прикладные журналы запросов и агрегированная статистика очищаются по настройкам администратора; исходные значения — 7 и 90 дней соответственно. Данные лицензий и связь с Telegram сохраняются для обслуживания доступа, история оплат — для сверки и обращений. Резервные копии могут храниться отдельно от рабочих журналов.

[GitHub Issues](https://github.com/mircopblane-dot/flow-remote-helper-support/issues) — публичные обращения. Не публикуйте там ключ лицензии, cookies, токены или платёжные реквизиты. Для вопроса об оплате укажите номер заказа из бота и примерное время. GitHub и Telegram обрабатывают данные по собственным правилам.

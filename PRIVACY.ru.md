# Flow Remote Helper: какие данные передаются

Flow Remote Helper — расширение Chrome, которое получает с нашего сервера параметры для работы с текущей версией Google Flow и проверяет ваш ключ доступа. Для этого требуется интернет.

Ниже отдельно описаны запросы расширения, ответы сервера, данные на компьютере, Telegram-бот и поддержка. Описание относится к версии 3.0.5; в 3.0.4 ещё нет просмотра срока доступа в настройках.

## Что расширение отправляет на наш сервер

Запросы направляются по HTTPS на `95.182.96.230:8443`. Содержание зависит от действия:

| Данные | Когда передаются и зачем |
| --- | --- |
| **Ключ доступа** | При проверке ключа в настройках и при подключении Flow. Сервер проверяет, существует ли ключ, действует ли он и не закончился ли доступ. Ключ передаётся в заголовке запроса, а не в адресе страницы. |
| **Идентификатор сборки Flow** | При подключении Flow, чтобы получить параметры для этой сборки. Идентификатор может содержать язык интерфейса. |
| **Публичный адрес JavaScript-файла сборки на `www.gstatic.com`** | При подключении Flow. Это адрес общего файла приложения Google, а не адрес вашего проекта. Он передаётся без дополнительных параметров после `?` и части после `#`. При необходимости сервер сам получает этот публичный файл у Google. |
| **Случайное значение запроса** | При подключении Flow. Позволяет расширению убедиться, что ответ относится именно к его текущему запросу. Оно не содержит имя, email или идентификатор аккаунта Google. |

При применении ключа и нажатии «Проверить доступ» расширение отправляет только ключ и обычные сетевые данные соединения. Сведения о сборке Flow для этой проверки не нужны.

## Что сервер возвращает расширению

**При проверке ключа в настройках:** состояние доступа, дату и время его окончания и время проверки. Расширение показывает, действителен ли ключ, истёк ли он, приостановлен или отозван. Если ключ не найден или сервер недоступен, появляется соответствующее сообщение. Срок лицензии — это срок вашего доступа, а не срок отдельного технического разрешения.

**При подключении Flow:** статус подготовки, сообщение об ошибке или параметры совместимости для конкретной сборки. Готовый ответ содержит параметры, случайное значение исходного запроса, привязку к сборке и её публичному адресу, время выдачи, срок технического разрешения и цифровую подпись. Расширение проверяет подпись и соответствие запросу перед применением. Техническое разрешение действует не более пяти минут и затем обновляется.

Ответы содержат данные и настройки. **Исполняемый код расширения с нашего сервера не скачивается.** Изменения самого расширения устанавливаются отдельным обновлением.

## Когда происходят обращения

- При применении ключа и открытии настроек с сохранённым ключом — для показа состояния и срока доступа. Недавно полученный результат может использоваться повторно без нового запроса.
- При нажатии «Проверить доступ» — для обновления сведений.
- При открытии Flow, включая повторное открытие после подготовки, — для получения актуального разрешения.
- Периодически, пока вкладка Flow открыта, — для продления технического разрешения.
- При временной сетевой ошибке или ожидании подготовки — повторные попытки. Это не отправка новых категорий данных.

## Сетевые данные и статистика

Как и при обычном обращении к сайту, наш сервер видит IP-адрес подключения и стандартные заголовки браузера, например сведения о браузере в User-Agent. HTTPS защищает содержание соединения при передаче, но не скрывает его от сервера-получателя.

В прикладной статистике проверок Flow записываются:

- связь обращения с лицензией, если она распознана;
- время и результат проверки, код ответа и длительность обработки;
- число обращений и сведения о поддерживаемой сборке или её выпуске.

**IP-адрес, User-Agent и полный ключ в эту статистику не записываются.** Это не означает, что сервер или инфраструктура хостинга не видят сетевых данных соединения. Счётчики обращений также не являются счётчиками генераций, проектов или действий внутри Flow.

## Что расширение не отправляет на наш сервер

- Cookies, пароли, токены авторизации и данные входа Google.
- Имя, email и содержимое Google-аккаунта.
- Проекты Flow, промпты, загруженные изображения и видео, результаты генераций.
- HTML и снимки страниц, историю посещения других сайтов.
- Локальные файлы, содержимое буфера обмена и список профилей Chrome.

Расширение не направляет весь браузерный трафик через наш сервер. Сам Google Flow продолжает обмениваться данными с Google обычным образом; перечисленное выше описывает именно запросы **на наш сервер**.

## Что находится на компьютере

**Ключ** хранится в локальном хранилище расширения в выбранном профиле Chrome. Его можно показать и скопировать в настройках. Ключ не записывается в хранилище страницы Flow и не передаётся её скриптам. В буфер обмена ключ попадает только после вашего нажатия «Копировать»; расширение не читает содержимое буфера.

**Полученные параметры Flow** временно сохраняются во вкладке для повторного открытия страницы. Chrome может восстановить это хранилище вместе с вкладкой, но для подключения всё равно требуется свежее разрешение сервера.

**Состояние ключа и срок** показываются по ответу сервера. При неудачной повторной проверке настройки могут показать ранее полученные сведения с отметкой о времени проверки; это не подтверждение, что доступ сейчас действует.

**Windows-установщик** распаковывает файлы локально. Он читает названия и пути профилей Chrome, чтобы предложить нужный профиль, но не отправляет их на сервер. Сам установщик не выполняет сетевых запросов, не требует прав администратора и не создаёт фоновую службу.

## Telegram-бот

Получить ключ и посмотреть свой доступ можно в [@testery_ai_bot](https://t.me/testery_ai_bot?start=flow), командой `/flow`.

При обращении Telegram передаёт боту ваш Telegram ID, отправленную команду или сообщение и сведения о нажатой кнопке. В обновлении Telegram также могут присутствовать стандартные данные профиля, например имя и username, если он задан. Для выдачи доступа сервис использует Telegram ID и хранит его связь с лицензией, вид доступа и срок. Для повторного показа выданного ключа на сервере сохраняется его зашифрованная копия.

Бот отправляет вам сообщения о доступе, ключ и дату окончания. Расширение не передаёт боту содержимое вкладок, Google-аккаунт, проекты или промпты. Telegram обрабатывает переписку по собственным правилам.

## Поддержка

Обращения принимаются через [GitHub Issues](https://github.com/mircopblane-dot/flow-remote-helper-support/issues). Для обращения вы сами отправляете описание проблемы и, при необходимости, прикладываете снимок экрана. Расширение не загружает диагностику или снимки автоматически.

**Обращения публичны:** их текст, вложения и ваш профиль GitHub могут видеть другие пользователи. Не публикуйте ключ доступа, cookies, токены или пароли. Перед отправкой снимка скройте личные данные. GitHub обрабатывает обращения и данные подключения по собственным правилам.

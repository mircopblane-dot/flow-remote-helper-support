# Flow Remote Helper в Яндекс Браузере на Android

Инструкция по ручной установке обычного ZIP расширения на телефон или планшет.
Отдельное Android-приложение для этого способа не требуется.

**Статус: экспериментальная поддержка Android.** На 26 октября 2026 года
ручная установка клиента **3.0.11**, проверка ключа и 10 синтетических сценариев
механизма расширения прошли на Android 13 в Яндекс Браузере 26.8.7.49.
Вход в реальный Google-аккаунт, генерация и скачивание результата в самом Flow
не проверялись. Это не гарантия полной совместимости сервиса с Android.
Другие версии Android, браузера и расширения отдельно не проверялись.

Последний публичный выпуск на дату инструкции — **3.0.10**; проба 3.0.11
проводилась на тестовой сборке. Используйте только ZIP из официального раздела
[Releases](https://github.com/mircopblane-dot/flow-remote-helper-support/releases).
Публикация этой инструкции сама по себе не является выпуском новой версии.

## Что понадобится

- **Яндекс Браузер** для Android. В обычном Chrome для Android расширение
  установить нельзя.
- ZIP расширения из раздела Releases.
- Приложение «Файлы» или файловый менеджер с распаковкой ZIP.
- Ключ доступа из [Telegram-бота](https://t.me/testery_ai_bot?start=flow)
  и подключение к интернету.

Компьютер, USB-кабель, отладка Android по USB и root для установки не нужны.
«Режим разработчика» далее включается только на странице расширений браузера.

## 1. Скачать и распаковать расширение

1. Установите и откройте Яндекс Браузер. Завершите его начальную настройку;
   делать его браузером по умолчанию необязательно.
2. Откройте [последний публичный релиз](https://github.com/mircopblane-dot/flow-remote-helper-support/releases/latest)
   и раскройте список **Assets**, если он свёрнут.
3. Скачайте файл **`flow-remote-helper-vps-<версия>.zip`**. Например, в выпуске
   3.0.10 он называется `flow-remote-helper-vps-3.0.10.zip`.
   **EXE предназначен для Windows.** Архивы **Source code (zip/tar.gz)** содержат
   документацию публичного репозитория и для установки расширения не подходят.
4. В приложении «Файлы» распакуйте ZIP в отдельную постоянную папку внутри
   «Загрузки» / `Download`, например `Download/FlowRemoteHelper`.
5. Откройте распакованную папку. В ней должны лежать `manifest.json`,
   `main.js`, `bridge.js`, `worker.js`, `options.html` и папка `icons`.
   Если файловый менеджер создал ещё одну вложенную папку, используйте ту,
   в которой непосредственно находится `manifest.json`.

Папку расширения после установки не удаляйте и не перемещайте. Если файловый
менеджер предлагает очистить загрузки, оставьте эту папку на устройстве.

## 2. Загрузить папку в Яндекс Браузер

1. Введите **`browser://extensions`** в адресную строку Яндекс Браузера
   и перейдите по этому адресу. Его нужно ввести как адрес, а не искать в поиске.
2. Включите **«Режим разработчика» / Developer mode**.
3. Нажмите **«Загрузить распакованное расширение» / Load unpacked**.
4. В системном выборе папки перейдите в «Загрузки» / `Download`, затем
   **внутрь папки расширения**, где находится `manifest.json`.
5. Нажмите **«Использовать эту папку» / Use this folder**, затем разрешите
   Яндекс Браузеру доступ **к этой папке**. Выбирать весь `Download` или
   корень памяти устройства не требуется; Android может запрещать их выбор.
6. Дождитесь появления карточки **Flow Remote Helper — VPS edition**
   на странице расширений. Она должна быть включена.

В проверенной версии Яндекс Браузера 26.8.7.49 выбирается именно **папка**.
В других вариантах интерфейса может открыться выбор файла: тогда выберите
`manifest.json` внутри распакованного расширения. Официальная справка Яндекса:
[расширения на Android](https://yandex.com/support/browser-mobile-android-phone/ru/personal-settings/extensions).

## 3. Применить ключ

1. После установки настройки расширения обычно открываются автоматически.
   Если этого не произошло, откройте меню браузера → **«Расширения»** →
   **Flow Remote Helper**. Ещё один путь — карточка расширения на
   `browser://extensions` → **«Подробнее» / Details** → параметры расширения.
2. Вставьте свой ключ в поле **«Ключ доступа»** и нажмите **«Применить ключ»**.
3. Дождитесь ответа: расширение покажет состояние доступа и срок
   либо отметку **«Бессрочно»**. Срок зависит от выданного ключа;
   установка на Android его не изменяет.
4. Нажмите **«Открыть Flow»**. Оставьте вкладку открытой на время подготовки.
   При ошибке подготовки используйте **«Попробовать снова»**.

Для работы самого Flow потребуется вход в Google на странице сервиса.
Установка и активация расширения не подтверждают, что все функции Flow
доступны вашему аккаунту на Android.

## Обновление на Android

Windows-установщик и помощник «Обновление одной кнопкой» на Android не работают.
Кнопки **«Скачать установщик»** и **«Подключить помощник»** в текущих настройках
предназначены для Windows; для Android используйте ручное обновление:

1. Сохраните свой ключ в безопасном месте на случай повторной установки.
2. Скачайте новый ZIP из [Releases](https://github.com/mircopblane-dot/flow-remote-helper-support/releases/latest).
3. Распакуйте его и замените файлы **в прежней папке расширения**.
   `manifest.json` должен оставаться непосредственно в этой папке,
   а не оказаться во вложенной папке новой версии.
4. Откройте `browser://extensions` и нажмите **↻ / Reload** у карточки
   Flow Remote Helper. Дождитесь завершения перезагрузки.
5. Заново откройте или обновите вкладку Flow. Перезагрузка расширения
   сама по себе не подключает его к уже открытой странице.

При обновлении существующего расширения ключ обычно сохраняется.
Удаление и установка заново могут потребовать повторного ввода ключа.
Держите включённой только одну версию Flow Remote Helper.

## Если установка не получается

| Что происходит | Что проверить |
|---|---|
| Нет кнопки Load unpacked | Открыта ли страница `browser://extensions` именно в Яндекс Браузере и включён ли Developer mode. |
| Android пишет «Нельзя использовать эту папку» | Откройте отдельную папку расширения внутри Download; не выбирайте весь Download или корень памяти. |
| Не найден manifest.json | ZIP распакован? Не выбран ли архив Source code? Нет ли лишней вложенной папки? |
| Карточка установилась, но ключ не проверяется | Убедитесь, что ключ скопирован полностью, доступ к интернету есть, а текст ошибки записан точно. |
| Страница Flow не подхватила расширение | Проверьте, что оно включено, дождитесь его загрузки, затем заново откройте вкладку Flow. |
| Предлагается скачать EXE или подключить помощник | Это Windows-функции. На Android скачивайте ZIP и обновляйте вручную. |

Если проблема остаётся, [создайте обращение](https://github.com/mircopblane-dot/flow-remote-helper-support/issues/new)
и укажите модель устройства, версию Android, версию Яндекс Браузера,
версию расширения и точный текст ошибки. Отдельно уточните этап:
установка, проверка ключа, подготовка Flow или работа самого сервиса.

**Не публикуйте в Issues ключи, пароли, cookies или токены Google.**
Перед отправкой скриншота убедитесь, что на нём нет этих данных.

# Flow Remote Helper 3.0.3

Первый публичный выпуск приложения в GitHub Releases.

- Понятный экран подготовки: обычно 5–10 секунд.
- Автоматические повторы при временных сетевых сбоях и ответах сервера в пределах минуты на этап.
- Кнопка «Попробовать снова», если подключение не удалось.
- Установщик Windows с выбором профиля Chrome и пошаговой инструкцией подключения.

## Скачать

- `FlowRemoteHelper-Setup-3.0.3.exe` — установщик Windows, рекомендуемый вариант.
- `flow-remote-helper-vps-3.0.3.zip` — готовое расширение для ручной установки unpacked.
- `SHA256SUMS.txt` — контрольные суммы обоих файлов.

Установка вне Chrome Web Store: в Chrome требуется включить «Режим разработчика» и загрузить распакованное расширение. EXE не подписан сертификатом издателя. При обновлении нажмите ↻ у расширения в нужном профиле, ключ сохранится.

Ключ: [@testery_ai_bot → /flow](https://t.me/testery_ai_bot?start=flow). Один тест на 72 часа, затем 365 дней за 50 Stars.

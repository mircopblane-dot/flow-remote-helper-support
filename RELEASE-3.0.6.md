# Flow Remote Helper 3.0.6

- В настройках появилась кнопка **«Проверить обновления»**.
- Если опубликована новая версия, расширение показывает ссылку на её Windows-установщик и инструкцию обновления.
- Проверка выполняется только по нажатию и обращается напрямую к GitHub. Ключ доступа и сведения о Flow не отправляются.
- Для проверки добавлен доступ к `api.github.com`. Фоновых проверок и автоматической установки нет.

## Скачать и обновить

- `FlowRemoteHelper-Setup-3.0.6.exe` — установщик Windows.
- `flow-remote-helper-vps-3.0.6.zip` — готовое расширение для ручной установки.
- `SHA256SUMS.txt` — контрольные суммы файлов.

Запустите установщик, затем нажмите ↻ у расширения в `chrome://extensions`. При ручном обновлении замените файлы в прежней папке и также нажмите ↻. Ключ и настройки сохранятся. После этого откройте настройки значком расширения — раздел «Обновления» находится под карточкой доступа.

Чтобы получить эту кнопку в 3.0.5 и более ранних версиях, один раз обновитесь обычным способом. В дальнейшем кнопка поможет найти новый установщик; запуск установки и перезагрузка расширения остаются ручными.

Права администратора не нужны. EXE не подписан сертификатом издателя. Chrome требует «Режим разработчика» и загрузку распакованного расширения.

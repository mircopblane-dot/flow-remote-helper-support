# Flow Remote Helper 3.0.9

- Исправлено первое подключение помощника после Allow: отслеживается выдача разрешения Chrome, повторяется локальная проверка при временном отказе запуска.
- Во время подключения виден статус ожидания. При открытии настроек уже разрешённый помощник определяется автоматически.
- Сохраняются опциональная установка помощника, обновление по кнопке и ручной установщик. Ключ и прежний помощник 3.0.8 сохраняются; запускать установщик повторно не нужно, если помощник уже подключён.

## Обновить

В настройках 3.0.8 нажмите «Проверить обновления» → «Обновить до 3.0.9». После установки расширение перезагрузится и снова откроет настройки.

Без помощника скачайте `FlowRemoteHelper-Setup-3.0.9.exe`, запустите его и нажмите ↻ у расширения в chrome://extensions. Доступен также ZIP для ручной установки.

`flow-remote-helper-update-3.0.9.json` нужен помощнику для проверки подписи; вручную открывать не нужно. EXE пока не подписан сертификатом издателя, подпись пакета проверяет помощник.

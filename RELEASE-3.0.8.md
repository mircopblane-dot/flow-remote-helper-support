# Flow Remote Helper 3.0.8

- В Windows-установщике появился необязательный помощник «Обновление одной кнопкой». Его можно не устанавливать либо удалить позже тем же установщиком.
- С помощником: один раз нажмите «Подключить помощник» и разрешите связь в Chrome. Для следующего выпуска достаточно «Проверить обновления» → «Обновить». Расширение перезагрузится самостоятельно.
- Без помощника сохраняется ручное скачивание установщика и ↻ в chrome://extensions. Ключ сохраняется в обоих режимах.
- Пакеты проверяются по цифровой подписи и контрольной сумме. Помощник запускается только по команде, без службы, автозапуска и обращения к VPS.

Сам помощник устанавливается/обновляется через EXE. Первое подключение unpacked-расширения в Chrome остаётся ручным.

## Скачать

- `FlowRemoteHelper-Setup-3.0.8.exe` — установщик Windows с выбором помощника.
- `flow-remote-helper-vps-3.0.8.zip` — расширение для ручной установки.
- `flow-remote-helper-update-3.0.8.json` — подпись и сведения для помощника; вручную открывать не нужно.
- `SHA256SUMS.txt` — контрольные суммы.

EXE пока не подписан сертификатом издателя; подпись пакетов обновления проверяется самим помощником.

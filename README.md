# Поддержка Flow Remote Helper

[Создать обращение](https://github.com/mircopblane-dot/flow-remote-helper-support/issues/new/choose) · [Все обращения](https://github.com/mircopblane-dot/flow-remote-helper-support/issues)

## Доступ

В Telegram-боте [@testery_ai_bot](https://t.me/testery_ai_bot?start=flow) откройте раздел Flow. Один бесплатный тест действует 72 часа с момента выдачи. Годовой доступ: 365 дней за 50 Telegram Stars, разовая покупка без автоматического списания. Доступ выдаётся после подтверждения оплаты Telegram.

При повторном запросе бот показывает прежний ключ и срок. Для просмотра используйте /flow, по вопросам оплаты — /paysupport.

## Если Flow не открывается

1. Проверьте, что включена одна версия расширения и ключ сохранён в её настройках.
2. Откройте https://flow.google.com/ и оставьте вкладку открытой. Обычно подготовка занимает 5–10 секунд. При временном сбое расширение повторяет попытки до минуты.
3. Если появилось сообщение об ошибке, нажмите «Попробовать снова».
4. Если проблема повторяется, создайте Issue.

## Что указать в обращении

- Что вы пытались сделать и что произошло.
- Версию расширения, Chrome и операционную систему.
- Текст ошибки и снимок экрана без личных данных.
- По оплате: номер заказа из бота и примерное время оплаты.

Issues публичны. **Не публикуйте ключ лицензии, cookies, токены, пароли, полные платёжные реквизиты или данные Google-аккаунта.**

В этом репозитории размещены только инструкции и обращения пользователей.

# Flow Remote Helper

Расширение Chrome для работы с Flow с проверкой доступа через сервис совместимости.

**[Скачать установщик для Windows](https://github.com/mircopblane-dot/flow-remote-helper-support/releases/latest/download/FlowRemoteHelper-Setup-3.0.3.exe)** · [Все релизы](https://github.com/mircopblane-dot/flow-remote-helper-support/releases) · [Получить ключ в Telegram](https://t.me/testery_ai_bot?start=flow)

Текущий выпуск: **3.0.3**. В релизах доступны Windows EXE, ZIP для ручной установки и SHA-256 для проверки файлов. Автоматически создаваемые GitHub архивы Source code содержат документацию этого публичного репозитория. Готовое приложение — в EXE/ZIP релиза.

## Установка

1. Скачайте FlowRemoteHelper-Setup-3.0.3.exe из Releases и запустите. Права администратора не нужны. Установщик пока не имеет цифровой подписи издателя.
2. Выберите нужный профиль Chrome и подготовьте файлы.
3. Нажмите кнопку открытия Chrome и вставьте скопированный адрес в адресную строку. Включите «Режим разработчика» → «Загрузить распакованное» → выберите папку из установщика.
4. В настройках расширения сохраните ключ и откройте https://flow.google.com/.

Обычно подготовка занимает **5–10 секунд**. Оставьте вкладку открытой: при временном сбое запросы повторяются до минуты на этап. После подготовки Flow откроется автоматически. При ошибке нажмите «Попробовать снова».

Папку установленного расширения не удаляйте и не перемещайте. При обновлении используйте прежнюю папку и нажмите ↻ у расширения в chrome://extensions; ключ останется. Одновременно включайте одну версию Flow Helper. Для ручной установки без EXE распакуйте ZIP релиза и выберите папку через «Загрузить распакованное».

## Доступ

В [@testery_ai_bot](https://t.me/testery_ai_bot?start=flow) отправьте /flow.

- Бесплатный тест: **72 часа**, один раз на Telegram-пользователя.
- Годовой доступ: **365 дней за 50 Telegram Stars**, разовая покупка без автосписания.
- Повторный запрос показывает прежний ключ и срок. Годовой доступ включается после подтверждённой оплаты Telegram.

## Как работает приложение и какие данные передаёт

При открытии Flow расширение проверяет лицензию и получает от сервиса актуальные параметры для текущей версии Flow. На сервер по HTTPS передаются ключ, идентификатор сборки Flow, публичный адрес её JavaScript-файла и случайное значение запроса. Сервер также видит IP подключения и стандартные сетевые заголовки браузера; прикладная статистика содержит время, статус и длительность проверок, сведения о сборке и счётчики по лицензии.

**Cookies и токены Google, email аккаунта, проекты, промпты, фотографии и видео на наш сервер не отправляются.** Установщик не передаёт список Chrome-профилей. Telegram-выдача отдельно хранит Telegram ID, связь с лицензией и данные заказа/подтверждения оплаты.

Подробности и сроки хранения: [Какие данные передаются](PRIVACY.ru.md).

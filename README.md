# Flow Remote Helper

Расширение Chrome для работы с Flow с проверкой доступа через сервис совместимости.

**[Скачать установщик для Windows](https://github.com/mircopblane-dot/flow-remote-helper-support/releases/latest/download/FlowRemoteHelper-Setup-3.0.10.exe)** · [Все релизы](https://github.com/mircopblane-dot/flow-remote-helper-support/releases) · [Получить ключ в Telegram](https://t.me/testery_ai_bot?start=flow)

**Android: [установка в Яндекс Браузер](ANDROID_YANDEX.ru.md)** — ручная установка ZIP, экспериментальная поддержка. Проверены установка и механизм расширения в синтетических сценариях; реальная генерация в Flow на Android пока не проверялась.

Текущий выпуск: **3.0.10**. В релизах доступны Windows EXE, ZIP для ручной установки и SHA-256 для проверки файлов. Исходники приложения в публичные релизы не включаются; автоматически создаваемые GitHub архивы Source code содержат документацию этого репозитория.

## Установка на Windows

1. Скачайте `FlowRemoteHelper-Setup-3.0.10.exe` из раздела Releases и запустите его. Права администратора не нужны. Установщик пока не имеет цифровой подписи издателя.
2. Выберите нужный профиль Chrome и подготовьте файлы.
3. Откройте страницу расширений через кнопку установщика: вставьте скопированный адрес в адресную строку Chrome. Включите «Режим разработчика» и выберите «Загрузить распакованное», затем укажите папку из установщика.
4. В настройках расширения вставьте выданный ключ и нажмите «Применить ключ». После проверки появятся состояние доступа и срок либо отметка «Бессрочно». Затем нажмите «Открыть Flow».

Обычно подготовка занимает **5–10 секунд**. Оставьте вкладку открытой: при временном сбое расширение повторяет попытки до минуты, после подготовки Flow откроется автоматически. Если появилась ошибка, нажмите «Попробовать снова».

Папку установленного расширения не удаляйте и не перемещайте. При обновлении используйте прежнюю папку и нажмите ↻ у расширения в `chrome://extensions`; сохранённый ключ остаётся. Одновременно включайте одну версию Flow Helper. Для ручной установки без EXE распакуйте ZIP релиза и выберите полученную папку через «Загрузить распакованное».

В настройках можно показать и скопировать сохранённый ключ, посмотреть срок доступа и обновить сведения кнопкой «Проверить доступ». Настройки открываются нажатием на значок расширения.

## Обновления на Windows

В установщике можно выбрать **«Обновление одной кнопкой»**. При первой установке флажок включён; при повторной установке сохраняется прежний выбор. Для добавления или удаления помощника запустите установщик и измените этот флажок. Права администратора не нужны.

- **С помощником:** после подключения расширения нажмите в его настройках «Подключить помощник» и разрешите связь с локальной программой. Затем «Проверить обновления» → «Обновить до …». Помощник скачает и проверит подписанный пакет, установит его, расширение перезагрузится само.
- **Без помощника:** «Проверить обновления» → «Скачать установщик», запустить EXE и нажать ↻ у расширения в `chrome://extensions`. Для ZIP-установок этот способ также доступен.

Ключ сохраняется в обоих случаях. Проверки и установка запускаются только по нажатию; постоянно работающей службы и фоновой установки нет. Пакеты скачиваются с GitHub. Если помощник недоступен, остаётся ссылка на ручной установщик.

Помощник добавляется один раз установщиком 3.0.8 или новее. Сам он обновляется через установщик; кнопка в расширении обновляет файлы расширения. Первое подключение unpacked-расширения к Chrome остаётся ручным.

## Доступ

В [@testery_ai_bot](https://t.me/testery_ai_bot?start=flow) отправьте `/flow`.

- Бесплатный тест: **72 часа**, один раз на Telegram-пользователя.
- Бессрочный доступ: **50 Telegram Stars**, разовая покупка без автоматического списания.
- Кнопка «Получить ключ» выдаёт первый тестовый ключ или показывает уже выданный. После подтверждённой оплаты тот же ключ становится бессрочным; заново вводить его в расширение не нужно. У уже выданных годовых ключей прежний срок сохраняется до новой покупки.

## Как работает приложение и какие данные передаёт

При открытии Flow расширение проверяет лицензию и получает от сервиса актуальные параметры для текущей версии Flow. На сервер по HTTPS передаются ключ, идентификатор сборки Flow, публичный адрес её JavaScript-файла и случайное значение запроса. Сервер также видит IP подключения и стандартные сетевые заголовки браузера; прикладная статистика содержит время, статус и длительность проверок, сведения о сборке и счётчики по лицензии.

**Cookies и токены Google, email аккаунта, проекты, промпты, фотографии и видео на наш сервер не отправляются.** Установщик не передаёт список Chrome-профилей. Telegram-выдача отдельно хранит Telegram ID, связь с лицензией и данные заказа/подтверждения оплаты.

Подробно о передаче и хранении данных: [Какие данные передаются](PRIVACY.ru.md).

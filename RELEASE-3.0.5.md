# Flow Remote Helper 3.0.5

- В настройках можно посмотреть и скопировать сохранённый ключ.
- Появились точная дата окончания доступа, оставшееся время и состояние ключа.
- При нажатии «Применить ключ» сразу проверяются его действительность и срок — открывать Flow для проверки не нужно.
- Добавлены кнопка повторной проверки, ссылки на Telegram-бота и поддержку. При отсутствии связи показывается, что проверка не завершена; сохранённый ключ остаётся на компьютере.
- Заново составлено описание передачи данных: отдельно указаны запросы расширения, ответы сервера, сетевые метаданные, статистика, локальное хранение, бот и GitHub Issues.

## Скачать и обновить

- `FlowRemoteHelper-Setup-3.0.5.exe` — установщик Windows.
- `flow-remote-helper-vps-3.0.5.zip` — готовое расширение для ручной установки.
- `SHA256SUMS.txt` — контрольные суммы файлов.

Запустите установщик и нажмите ↻ у расширения в `chrome://extensions`. При ручном обновлении замените файлы в прежней папке и также нажмите ↻. Ключ сохранится. Чтобы открыть настройки, нажмите значок расширения.

Права администратора не нужны. EXE не подписан сертификатом издателя. В Chrome требуется «Режим разработчика» и загрузка распакованного расширения.

# Flow Remote Helper 3.0.4

- Несколько вкладок одного профиля согласуют ожидание подготовки Flow, сокращая повторные запросы.
- Снижены фоновые расходы сервиса совместимости и обработка повторных проверок.
- Сохранены автоматические повторы при временных сбоях, проверка лицензии и индивидуальная проверка ответа для каждой вкладки.

## Скачать

- `FlowRemoteHelper-Setup-3.0.4.exe` — установщик Windows.
- `flow-remote-helper-vps-3.0.4.zip` — готовое расширение для ручной установки unpacked.
- `SHA256SUMS.txt` — контрольные суммы.

При обновлении запустите установщик, затем нажмите ↻ у расширения в `chrome://extensions`. Ключ сохранится. Для ручной установки замените файлы в прежней папке и также нажмите ↻. Права администратора не нужны; EXE не подписан сертификатом издателя.

Обычно подготовка занимает 5–10 секунд. При временном сбое расширение повторяет попытки до минуты на этап.
